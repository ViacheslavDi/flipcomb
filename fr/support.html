Comment jouer ?

Glissez les pièces du bas vers le rayon. Touchez une pièce pour la tourner, deux fois pour la retourner. Son symbole doit tomber sur le même symbole du plateau. Les règles complètes sont dans l'app : touchez « ? » dans un niveau.

Un achat n'est pas arrivé

Ouvrez la boutique de miel et touchez « Restaurer les achats ». Vérifiez que vous utilisez le même identifiant Apple que pour l'achat.

Comment supprimer les publicités ?

Premium supprime définitivement les publicités entre les essais. Les vidéos contre une goutte de miel restent toujours facultatives.

Comment désactiver les rappels ?

Réglages de l'app → « Rappel quotidien », ou Réglages d'iOS → Notifications → Flipcomb.

J'ai perdu ma progression

La progression est stockée sur l'appareil et supprimée avec l'app. Les achats peuvent toujours être restaurés.
